# ANSYS Automation

Автоматизация настройки расчетов опорных конструкций в ANSYS Mechanical.

## Описание

Проект автоматизирует процесс подготовки конечно-элементных моделей опорных конструкций, включая:
- Автоматическое определение типа конструкции
- Настройку граничных условий и нагрузок
- Конфигурацию сетки и контактов
- Применение болтовых соединений
- Настройку результатов расчета

## Возможности

### Автоматическое определение типа конструкции
- Анализ имени модели по регулярным выражениям
- Поддержка различных форматов именования
- Определение конфигурации по Named Selections

### Гибкая система конфигураций
- Базовые настройки для всех конструкций
- Специфичные настройки для каждого типа конструкции
- Иерархическое слияние конфигураций

### Поддержка различных типов граничных условий
- Fixed Support (жесткая заделка)
- Displacement (перемещение)
- Remote Displacement (удаленное перемещение с фиксацией поворотов)
- Remote Force (удаленная сила)
- Frictionless Support (опора без трения)
- Compression Only (работа только на сжатие)

### Типы нагрузок
- Силы (Force) с компонентами X, Y, Z
- Моменты (Moment) с компонентами X, Y, Z
- Давление (Pressure)
- Температура (Temperature)
- Болтовая предзатяжка

### Автоматическая настройка контактов
- Определение контактных пар по паттернам имен
- Настройка типов контактов (Bonded, Frictional)
- Конфигурация параметров трения

### Настройка сетки
- Индивидуальные параметры для различных компонентов
- Поддержка различных методов построения сетки
- Автоматическая группировка схожих элементов

## Использование

### Базовая настройка

1. Подготовьте модель в ANSYS Mechanical с Named Selections для граничных условий и нагрузок
2. Именуйте модель согласно шаблону (например, `151-02-F2`)
3. Запустите скрипт в Scripting Console ANSYS

```python
import sys
sys.path.append(r'путь\к\проекту')
from main import run_automated_analysis

run_automated_analysis()
```

### Настройка для специфического типа конструкции

Создайте файл `structure_{тип}_config.json` в папке конфигураций:

```json
{
  "boundary_conditions": {
    "fixed_support": "my_fixed_ns",
    "remote_displacement": "my_remote_disp_ns",
    "remote_displacement_lock_rotations": ["X", "Y", "Z"]
  },
  "loads": {
    "force": "my_force_ns",
    "moment": "my_moment_ns"
  },
  "load_database": {
    "151": {
      "02": {
        "F1": {
          "nominal_forces": {"fx": 100, "fy": 250, "fz": 500},
          "nominal_moments": {"mx": 0, "my": 15000, "mz": 0}
        }
      }
    }
  }
}
```

## Требования
